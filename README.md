# demucs-offline — минусовка из любого аудиофайла, без интернета

Локальный комплект: разделяет трек на стемы моделью **Demucs v4 (htdemucs_6s)** и собирает
**минусовку без гитары**. Всё считается на CPU прямо на машине — ни одного сетевого запроса:
веса лежат в `models\`, python-пакеты — в `wheels\`, сеть в скриптах блокируется принудительно.

Работает с любым mp3 (а также wav/flac/ogg): моно/стерео, любая частота дискретизации,
ID3-теги, имена с пробелами и кириллицей. ffmpeg не нужен: mp3 читает libsndfile,
пишет LAME (lameenc).

---

## Быстрый старт

```cmd
setup_offline.cmd                                  :: один раз: создать .venv из wheels (без сети)
make_backing.cmd "D:\music\song.mp3"               :: минусовка + отдельно гитара
```

Результат — в папке `backing_out\` рядом с текущим каталогом:

| Файл | Что это |
|---|---|
| `song_backing.mp3` / `.wav` | минусовка без гитары (mp3 320 kbps с наследованными тегами, wav 24 бит) |
| `song_guitar.mp3` / `.wav` | удалённая гитара отдельным треком (учиться/сверяться) |
| `report.json` | отчёт: уровни, тайминги, доля гитары по полосам, проверка подавления |

Если `.venv` ещё нет — `make_backing.cmd` попробует системный python и предупредит.

## Перенос на другую машину (без интернета)

На этой машине:

```powershell
powershell -ExecutionPolicy Bypass -File .\pack_bundle.ps1 -Zip
```

Появится `dist\demucs-offline\` и `dist\demucs-offline.zip` (~270 МБ, без `.venv`).
На целевой машине (Windows x64, **Python 3.12 x64**):

```cmd
setup_offline.cmd
make_backing.cmd "D:\music\song.mp3"
```

`setup_offline.cmd` ставит пакеты строго локально (`pip install --no-index --find-links wheels`),
затем сам прогоняет самопроверку. Интернет не нужен ни на одном шаге.

Можно вообще не ставить Python: перенесите уже готовую папку `.venv` с этой машины
(тот же Python 3.12 x64 и Windows x64, желательно тот же путь — иначе пересоздайте).

## Параметры

```
make_backing.cmd ФАЙЛ [ФАЙЛ ...] [-o ПАПКА] [опции]
```

| Опция | По умолчанию | Смысл |
|---|---|---|
| `-o`, `--out` | `backing_out` | папка результата |
| `-r`, `--recursive` | выкл | обходить папки рекурсивно |
| `--force` | выкл | перезаписывать готовые файлы (по умолчанию они пропускаются) |
| `--dry-run` | — | показать план без обработки |
| `-n`, `--model` | `htdemucs_6s` | модель Demucs; есть также `htdemucs` (4 стема, без гитары) |
| `--models-dir` | `<комплект>\models` | где лежат веса `.th` и `.yaml` |
| `--shifts` | `2` | усреднение по сдвигам: 1 быстро, 2–4 чище и дольше |
| `--overlap` | `0.5` | перекрытие сегментов 0…1 |
| `--threads` | авто | число потоков torch |
| `--exclude` | `guitar` | какие стемы убрать (например `guitar,vocals` — минус с вокалом) |
| `--suppress` | `0.8` | зачистка остатков удалённого инструмента (0 = выкл, 1.2–2 = жёстче) |
| `--mask-floor` | `0.45` | предел подавления одного бина: 0 — «до нуля», 0.45 ≈ −7 дБ |
| `--target-rms-db` | как у исходника | громкость результата в dBFS |
| `--mp3-bitrate` | `320` | битрейт mp3 |
| `--no-mp3` / `--no-wav` | — | не писать соответствующий формат |
| `--keep-sr` | выкл | вернуть исходную частоту (иначе 44.1 кГц, на ней работает модель) |
| `--stems` | выкл | сохранить все стемы в `<имя>_stems\*.wav` |
| `--no-guitar` | выкл | не писать отдельную дорожку удалённого инструмента |
| `--verify` | выкл | контрольный прогон разделения по готовой минусовке (сколько гитары осталось) |
| `--max-seconds N` | — | обработать только первые N секунд (быстрая проверка) |
| `--report ФАЙЛ` | `<out>\report.json` | JSON-отчёт |
| `--allow-network` | выкл | разрешить сеть (по умолчанию заблокирована) |

Примеры:

```cmd
:: папка целиком, с сохранением стемов и проверкой
make_backing.cmd "D:\music\album" --stems --verify

:: жёстче убрать гитару (риск: «глуше» середина)
make_backing.cmd song.mp3 --suppress 1.4 --mask-floor 0.3

:: аккуратный вариант без зачистки
make_backing.cmd song.mp3 --suppress 0 --shifts 2

:: минус без гитары и вокала (караоке-минус)
make_backing.cmd song.mp3 --exclude guitar,vocals -o D:\karaoke

:: пробный прогон на 30 секундах
make_backing.cmd song.mp3 --max-seconds 30 --verify
```

Все параметры — в `make_backing.cmd --help`.

## Как это работает

1. **Декодирование** — libsndfile (mp3/mpg123, wav, flac, ogg), без ffmpeg; NaN/Inf вычищаются,
   моно дублируется в стерео, частота приводится к 44.1 кГц (julius).
2. **Разделение** — `htdemucs_6s`: drums, bass, other, vocals, **guitar**, piano.
   Веса `models/5c90dfd2-34c22ccb.th` проверяются по sha256, имя файла содержит префикс хеша.
   `shifts=2` усредняет результат по двум случайным сдвигам (меньше артефактов).
3. **Сборка минусовки** — сумма всех стемов, кроме `--exclude` (по умолчанию `guitar`).
4. **Зачистка остатков** — винеровская маска по STFT (4096/1024): бины, объясняемые гитарным
   стемом, приглушаются, но не сильнее `--mask-floor`. Это убирает «призвук» гитары, осевший
   в vocals/other.
5. **Громкость** — RMS приводится к уровню исходника (или `--target-rms-db`), затем мягкий
   лимитер tanh (порог 0.88) и потолок −0.5 dBFS: клиппинга нет.
6. **Запись** — wav 24 бита (libsndfile) и mp3 320 kbps (LAME/lameenc) с ID3v2.4-тегами,
   унаследованными от исходника (к названию добавляется « - backing track»).

## Скорость, память, качество

* Скорость на CPU (12 логических ядер, torch 2.15): примерно **2×…2.7× длительности трека**
  при `--shifts 2`. Трек 3:30 — около 6–8 минут.
* Память: стемы в float32 44.1 кГц стерео ≈ **2 МБ на секунду на 6 стемов**
  (5 минут ≈ 0.6 ГБ, 10 минут ≈ 1.3 ГБ). Скрипт печатает оценку перед запуском.
* Качество зависит от материала: гитара, доминирующая в миксе, удаляется лучше (подавление
  35–45 дБ по контрольному прогону); акустика, перекрывающаяся с вокалом, — хуже (20–30 дБ).
  Отчёт `report.json` содержит `guitar_share_pct` и (с `--verify`) `attenuation_db`.
* Если гитары в треке почти нет, скрипт предупредит: «гитара в треке почти не найдена»,
  и минусовка будет практически равна оригиналу.

## Самопроверка

```cmd
.venv\Scripts\python.exe src\offline_check.py
```

Проверяет: python 3.12 x64, наличие модулей, целостность весов (sha256), wheel-файлы,
кодирование/декодирование mp3 без ffmpeg, блокировку сети, пробное разделение
синтетического сигнала (6 с) и запись mp3 с тегами. Код возврата 0 — всё готово.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| `не найдено окружение` | запустить `setup_offline.cmd` |
| `AuthorizationManager check failed` / скрипт не запускается | использовать `.cmd`-обёртки или `powershell -ExecutionPolicy Bypass -File setup_offline.ps1` |
| `Python 3.12 x64 не найден` | поставить Python 3.12 x64 или указать `setup_offline.cmd -Python "C:\Python312\python.exe"` |
| `не удалось декодировать файл` | файл битый или это не аудио (например mp4/aac) — перекодировать в mp3/wav |
| минусовка «глухая», пропал вокал | уменьшить `--suppress` (например `--suppress 0` или `--suppress 0.5 --mask-floor 0.6`) |
| гитара слышна | увеличить `--suppress 1.4 --mask-floor 0.3`, попробовать `--shifts 4` |
| мало ОЗУ на длинном треке | обрабатывать по частям: `--max-seconds` не подходит для готового файла, лучше разрезать mp3 и обработать кусками |
| нужен исходный битрейт/частота | `--keep-sr`, `--mp3-bitrate 256` |

## Состав комплекта

```
demucs-offline\
  make_backing.cmd / .ps1     запуск обработки
  setup_offline.cmd / .ps1    создание .venv из wheels (без сети)
  pack_bundle.ps1             сборка переносимого комплекта (+zip)
  src\backing_lib.py          библиотека: разделение, микс, экспорт, offline-guard
  src\make_backing.py         CLI
  src\offline_check.py        самопроверка
  src\make_test_audio.py      генератор тестовых mp3
  models\                     веса htdemucs_6s (55 МБ) и htdemucs (84 МБ) + yaml
  wheels\                     все python-пакеты для офлайн-установки
  .venv\                      окружение (создаётся setup_offline; ~0.7 ГБ, можно удалить)
```
