# Лицензии компонентов комплекта

Комплект использует следующие открытые компоненты. Файлы лицензий лежат внутри
соответствующих пакетов в `.venv\Lib\site-packages\<пакет>\` (или в дистрибутивах
`*.dist-info\licenses`).

| Компонент | Версия | Лицензия | Что используется |
|---|---|---|---|
| Demucs | 4.1.0 | MIT (Copyright Meta Platforms, Inc.) | код разделения стемов |
| Веса htdemucs / htdemucs_6s | — | распространяются в репозитории Demucs (MIT) | модель `models\*.th` |
| PyTorch (CPU) | 2.15.0 | BSD-3-Clause | инференс модели |
| numpy | 2.5.5 | BSD-3-Clause | массивы, STFT |
| soundfile | 0.14.0 | BSD-3-Clause | чтение/запись звука |
| libsndfile | 1.2.2 (в wheel) | LGPL-2.1 | декодирование wav/flac/ogg/mp3 |
| libmpg123 | (в составе libsndfile) | LGPL-2.1 | декодирование mp3 |
| lameenc | 1.9.0 | MIT | обёртка LAME |
| LAME | (в составе lameenc) | LGPL-2.0 | кодирование mp3 |
| julius | 0.2.8 | MIT | ресемплинг |
| einops, tqdm, PyYAML, sympy и др. | см. `wheels\` | MIT / BSD / PSF | зависимости Demucs |

## Практические замечания

* **MP3**: патенты на MP3 истекли (2017), кодирование/декодирование свободно.
* **LGPL** (libsndfile, libmpg123, LAME) используется как динамически подключаемые
  библиотеки — это не накладывает требований на ваш собственный код; при
  распространении комплекта сохраняйте тексты лицензий и возможность замены
  библиотек (они лежат отдельными `.dll` в wheel-файлах).
* **Модель Demucs**: код и веса опубликованы Meta под MIT; для коммерческого
  использования сверьтесь с актуальным текстом лицензии в репозитории Demucs.
* Аудио, которое вы обрабатываете, должно быть у вас на законных основаниях
  (личное использование / обучение). Комплект не содержит музыки — только код и веса.
